# Developer's Note

Hi, I'm Mun Kyung!

The reason I started developing this software was quite simple: I wanted anyone, regardless of their financial circumstances, to be able to study econometrics using the same tools and methods that are standard in academia. With that goal in mind, I spent the past four or five months developing this software.

To be fair, I expect there are still quite a few bugs. Nevertheless, I've put a great deal of effort into making sure that, at the very least, the software is functional enough for everyday use. There's certainly plenty of room for improvement, but since it's freeware, I hope some of you might be willing to help improve it along the way.

I actually wanted to polish it a little more before releasing it to the public. Unfortunately, I've run out of money to continue development, so I've decided to leave it at this stage for now. Besides, throughout the development process, **I had this constant itch to get it finished**, with the same thought running through my mind: "I really need to finish this. I really need to finish this." So I suppose that played a part in my decision to finally wrap things up, too.

There's still a long way to go before I'd consider this software suitable for serious academic research. However, I believe it should be more than capable of handling coursework and reports at the undergraduate level, and even at the graduate level.

One thing I'm particularly proud of is that there are no artificial restrictions on the number of variables or CPU cores you can use. (Although, since my own computer only has four cores, I've only been able to test it with up to four.)

I sincerely hope this software proves useful to anyone who gives it a try. If it makes studying econometrics even a little easier or more accessible, that alone would make this whole endeavour worthwhile.

And finally, donations would be… very much appreciated.

# 개발자 노트

안녕하세요. 개발자 김문경입니다.

먼저 이 소프트웨어를 개발하게 된 계기는 단순합니다. 누구든지 돈이 있든 없든, 학계의 표준에 따라 계량경제학을 공부할 수 있으면 좋겠다는 바람에서 시작했습니다. 그런 생각 하나로 4~5개월에 걸쳐 이 소프트웨어를 개발하게 되었습니다.

사실 아직도 버그가 꽤 많을 것으로 예상됩니다만, 적어도 기본적인 사용에는 무리가 없는 수준으로 완성하고자 정말 많이 노력했습니다. 아직 미진한 부분이 많겠지만, 프리웨어인 만큼 여러분도 함께 이 소프트웨어를 고쳐 나갈 수 있으면 좋겠습니다.

사실은 조금 더 완성도를 높인 뒤 세상에 공개하고 싶었습니다. 하지만 개발을 이어 나갈 자금이 부족해 일단 이 정도 수준에서 멈추게 되었습니다. 개발하는 동안 '얼른 끝마쳐야지, 끝마쳐야지' 하는 생각이 계속 마음 한구석에 남아 있었던 것도 이쯤에서 일단락 짓게 된 이유이기도 하고요.

연구용으로 사용하기에는 아직 갈 길이 멉니다만, 학부는 물론 대학원 수준에서 보고서를 작성하거나 과제를 수행하는 데에는 충분히 쓸 만할 것이라고 생각합니다. 특히 변수 개수에 제한이 없고, 연산 코어 수도 별도로 제한하지 않았다는 점은 나름 자랑스럽게 생각합니다. (제 컴퓨터가 4코어라 실제로 확인해 본 것은 4코어까지입니다만.)

누구나 이 소프트웨어를 유용하게 사용하실 수 있기를 바랍니다. 계량경제학을 공부하시는 데 조금이라도 도움이 된다면 개발자로서 더 바랄 것이 없겠습니다.

마지막으로, 기부도… 받을 수 있으면 좋겠습니다.
