These names are used in a purely nominative sense — to identify the command
syntax a user already knows. They are accepted only while the
"external-library compatibility names" setting is enabled; you can turn it off
at any time with `set extcompat off`, after which PIET responds only to its own
native command names.

If you are the author of one of these packages and would prefer that PIET not
accept your command name, please open an issue (section 5) and we
will remove it.
